§9 CSS 은닉 처리 규칙 (K-3)
==============================================================================
  (1) 지배 검사 — M5(상주 메모리) 미수집으로 **부분 적용**(J-a/J-b/은닉 CPU만).
    CSS vs F-i: 지배 깨짐 — J-b @ f=0.1 s=100 rate=10 (열세)
    CSS vs F-ii: 지배 깨짐 — J-a @ f=0.1 s=1 rate=0 (비결정)
    CSS vs F-iii: 지배 깨짐 — J-a @ f=0.1 s=1 rate=0 (비결정)
    ⇒ 지배 불성립 — F 기계장치 도입 근거는 M5 없이도 **상실되지 않음** 확정
  (2) 거울상 의무 검사 — F 변형의 B-승리 셀에서 CSS가 동등 이상인가.
    F-i: B-승리 7조건 중 CSS 동등 이상 3 → 거울상 의무 미발동
    F-ii: B-승리 5조건 중 CSS 동등 이상 0 → 거울상 의무 미발동
